# Edge Text Reader

Android app tối giản: dán văn bản và đọc bằng Microsoft Edge TTS.

## MVP

- Dán text trực tiếp
- Giọng `vi-VN-HoaiMyNeural` / `vi-VN-NamMinhNeural`
- Tốc độ 0.75x–1.75x
- Đọc / Tạm dừng / Dừng
- Chia văn bản thành các cụm nhỏ
- Prefetch cụm tiếp theo
- Android MediaPlayer phát MP3 native

Không phụ thuộc MoRealm, EPUB hay System TTS.

> Edge TTS dùng endpoint read-aloud không chính thức của Microsoft Edge, vì vậy Microsoft có thể thay đổi giao thức trong tương lai.
